# Pelican Cyclist · 鹈鹕骑车

一只白色鹈鹕骑着黑色公路自行车沿街骑行的循环动画，纯前端单文件实现，无任何依赖。

## 动画效果

- **车轮联动**：双轮辐条随曲柄同步旋转，链条、牙盘、脚踏随曲柄转动
- **双腿踩踏**：基于两连杆反向运动学（IK）实时计算膝盖位置，双腿相差半圈交替蹬踏
- **视差背景**：远景楼房、中景树木、路面虚线以不同速度滚动，营造前进感
- **车身颠簸**：骑行过程中车体随曲柄节奏轻微上下浮动
- **交互控制**：播放 / 暂停，骑行速度滑块（0.2× – 2×）

## 本地运行

直接用浏览器打开 `index.html` 即可，无需构建或安装依赖：

```
double-click index.html
```

或起一个本地静态服务器：

```bash
npx serve .
# 或
python -m http.server 8080
```

## 实现要点

- 场景与角色全部由内联 SVG 绘制，侧视公路车几何（后轴 / 中轴 / 头管 / 前轴）固定坐标
- `requestAnimationFrame` 驱动每一帧：根据行驶距离推导车轮角与曲柄角，再反推双脚位置
- 腿部 IK：给定髋部固定点与脚踏目标点，按大腿 / 小腿长度求解膝盖朝向（膝盖始终朝前）
- 背景元素由 JS 按间距平铺，超出视口后循环回卷，保证无限滚动无跳变
